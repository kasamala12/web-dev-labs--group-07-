# LAB 4: Understanding Layout Control in CSS

## Objective
This project demonstrates layout control in CSS using:

- Box Model
- Positioning
- Float and Clear

## Features
- Fixed header
- Sticky navigation bar
- Three styled content boxes
- Absolute positioned label
- Two-column float layout
- Cleared footer

## Files Included
- index.html
- styles.css
- README.md

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Open the project folder
2. Double click index.html
3. View the webpage in your browser
