# Student Grade Calculator

## Objective
The objective of this practical activity was to develop a Student Grade Calculator Web Application using HTML, CSS, and JavaScript. The application captures user input, validates the entered score, calculates the corresponding grade, and updates the webpage dynamically using DOM manipulation without reloading the page.

## What Was Done
The following tasks were completed:

- Created a user interface using HTML and CSS.
- Added an input field for entering student scores.
- Added a button to calculate grades.
- Implemented JavaScript event handling using a click event listener.
- Validated user input to ensure scores are between 0 and 100.
- Calculated grades using if-else control statements.
- Displayed results dynamically using DOM manipulation.
- Cleared the input field after each calculation.
- Added optional features such as:
  - Color-coded grades.
  - Grade descriptions (Excellent, Very Good, Good, Pass, Fail).
  - Enter key support for grade calculation.

## Challenges Faced
During the development process, the following challenges were encountered:

- Configuring Live Server and opening the correct HTML file.
- Linking external CSS and JavaScript files correctly.
- Implementing input validation for invalid scores.
- Styling the interface to achieve a professional appearance.
- Testing different score ranges to ensure correct grade assignment.
